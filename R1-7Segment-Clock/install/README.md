# R1 7-Segment Clock Install Assets

Files used for Rabbit R1 Add via QR installation.

## Files

- creation-payload.json: JSON payload encoded into install QR
- public-app-url.txt: Hosted app URL used by the payload
- qr-source-url.txt: API URL that generates the QR image from payload
- publish-pages.sh: Push current branch and update pages branch
