# R1-Creations

Collection of Rabbit R1-compatible app experiments and prototypes.

## Apps

- `TNG-Tricorder`: LCARS-inspired tricorder scan interface (static web app).
- `R1-Launcher`: App hub for launching creations and external targets.
- `Hulkify`: Camera creation that captures photos and submits a Hulk-style magic photo prompt.
- `BBC-News`: LCARS-themed BBC RSS reader with categories, headlines, and article view.

## Repository Layout

- `TNG-Tricorder/`: App #1 and its implementation files.
- `R1-Launcher/`: Launcher app and event relay tooling.
- `Hulkify/`: Camera-driven magic-photo creation.
- `BBC-News/`: LCARS-themed BBC RSS news reader.
